# Installation and updates

Download the APK and SHA256SUMS from this repository's Releases. Verify the hash, then install using a method allowed by the Android device. This project does not modify device installation policy.

Open the application and confirm the main interface appears. A setup/authentication notice indicates prerequisites still need configuration; it is not completed projection.

For updates, use a higher-versionCode maintainer APK with the same package and signing certificate. An app with a different package or signing certificate is a separate installation. Development builds use the `.debug` package suffix.

No phone-projection acceptance is implied by the installation/startup check. Record device Android version, APK version and specific errors when reporting compatibility problems. Review diagnostic logs before sharing them.
